# Protify
Portify is a full-stack financial portfolio optimization and analysis system that enables users to analyze stock market data, perform sector-wise evaluation, and generate optimized investment portfolios.  
The application uses a modern React + Vite frontend and a Python FastAPI backend to process financial datasets and deliver optimized portfolio insights.It gives u information regarding the investments to make based on the risk evaluation of exisiting stocks and its history 


# Key Features

- Portfolio optimization using market data
- Sector-wise stock analysis
- Financial data cleaning & preprocessing
- Interactive UI for portfolio visualization
- REST API-driven backend


# Tech Stack Used

## Frontend
- React.js
- Vite

- JavaScript (JSX)
- PostCSS

## Backend
- Python 3
- FastAPI

## Data & Libraries
